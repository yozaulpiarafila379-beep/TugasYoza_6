1.Sealed Class

  • Result merupakan sealed class yang berfungsi sebagai tipe dasar untuk merepresentasikan suatu hasil dalam pemrograman.
  • Sealed class membatasi pewarisan hanya pada class yang berada dalam satu file yang sama, sehingga struktur program lebih aman dan terkontrol.
  • Success adalah turunan dari Result yang digunakan untuk merepresentasikan kondisi berhasil, dengan atribut message sebagai informasi hasil.
  • Failure adalah turunan dari Result yang digunakan untuk merepresentasikan kondisi gagal, dengan atribut error sebagai informasi kesalahan.
  • Konsep ini menerapkan prinsip Object-Oriented Programming (OOP), khususnya inheritance dan polymorphism, dalam pengelolaan hasil.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

sealed class Result {}

class Success extends Result {
  final String message;
  Success(this.message);
}

class Failure extends Result {
  final String error;
  Failure(this.error);
}

void main() {
  Result result = Success("Berhasil!");

  if (result is Success) {
    print(result.message);
  } else if (result is Failure) {
    print(result.error);
  }
}

2.Generic Class Box (Dasar)

  • Box<T> merupakan generic class yang digunakan untuk menyimpan data dengan tipe fleksibel.
  • Parameter <T> memungkinkan class digunakan untuk berbagai jenis data tanpa perlu membuat class baru.
  • Atribut data menyimpan nilai sesuai tipe yang ditentukan.
  • Method show() digunakan untuk menampilkan isi data.
  • Konsep ini menekankan type safety dan penggunaan ulang kode.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class Box {
  T data;

  Box(this.data);

  void show() {
    print("Isi Box: $data");
  }
}

void main() {
  var intBox = Box(100);
  var stringBox = Box("Halo Dart");

  intBox.show();
  stringBox.show();
}

3.Generic Class & Function

  • MyClass<T> merupakan generic class yang digunakan untuk menyimpan data dengan tipe yang fleksibel sesuai kebutuhan.
  • Parameter tipe <T> menunjukkan bahwa tipe data akan ditentukan saat objek dibuat, sehingga class dapat digunakan untuk berbagai jenis data.
  • Atribut data berfungsi sebagai tempat penyimpanan nilai sesuai dengan tipe yang telah ditentukan.
  • Method getData() digunakan untuk mengembalikan nilai dari atribut data.
  • myFunc<T> merupakan generic function yang menerima parameter dengan tipe fleksibel dan mengembalikan nilai dengan tipe yang sama.
  • Penggunaan generic pada class dan function mendukung type safety, sehingga kesalahan tipe data dapat dideteksi saat kompilasi.
  • Konsep ini juga meningkatkan efisiensi dan penggunaan ulang kode dalam pemrograman berorientasi objek.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class MyClass {
  T data;

  MyClass(this.data);

  T getData() {
    return data;
  }
}

T myFunc(T value) {
  return value;
}

void main() {
  var myIntClass = MyClass(10);
  var myStringClass = MyClass('test');

  print(myIntClass.getData());
  print(myStringClass.getData());

  int intValue = myFunc(100);
  var stringValue = myFunc('hello');

  print(intValue);
  print(stringValue);
}

4.Box dengan Getter & Setter

  • Box<T> merupakan pengembangan dari generic class dengan penerapan encapsulation.
  • Atribut _value bersifat private untuk melindungi data dari akses langsung.
  • Penggunaan tipe nullable memungkinkan nilai dapat bernilai kosong.
  • Getter digunakan untuk mengambil nilai secara aman, sedangkan setter digunakan untuk mengubah nilai.
  • Konsep ini menggabungkan generic dan encapsulation dalam OOP untuk meningkatkan keamanan dan kontrol data.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class Box {
  T? _value;

  Box(this._value);

  T? get value => _value;

  void setValue(T value) {
    _value = value;
  }
}

void main() {
  var intBox = Box(10);
  print('Int Box Value: ${intBox.value}');

  intBox.setValue(20);
  print('Int Box After Set: ${intBox.value}');

  var stringBox = Box('Hello, Generic!');
  print('String Box Value: ${stringBox.value}');

  stringBox.setValue('Hello World');
  print('String Box After Set: ${stringBox.value}');

  var doubleBox = Box(3.14);
  print('Double Box Value: ${doubleBox.value}');
}
